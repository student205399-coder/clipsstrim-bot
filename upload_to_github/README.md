# Telegram-бот для нарезок стримов (бесплатно, локально, без лимитов)

Делает вертикальные клипы 9:16 (15–60 секунд) из YouTube-ссылок:

- скачивает видео через `yt-dlp`;
- распознаёт речь локально через `faster-whisper` (модель скачивается один раз и кэшируется);
- **ищет интересные моменты по смыслу через локальную LLM в Ollama** — модель читает весь
  транскрипт с таймкодами и сама выбирает момент с реакцией (восхищение / восторг / агрессия /
  шок / смех), понимая иронию и контекст;
- **анализирует звук отдельно** и подсказывает модели, где были крики/визг/смех без слов —
  такие реакции больше не теряются;
- **проверяет мимику только в уже отобранных клипах** (улыбка, открытый рот, резкий наклон),
  добирая беззвучные визуальные реакции без тяжёлого видео-анализа всего стрима;
- делает финальный отбор: убирает похожие моменты и подтягивает начало клипа к реальной реакции;
- если Ollama недоступна — откат на быструю эвристику (громкость + словари эмоций);
- начинает клип прямо с реакции;
- добавляет субтитры в стиле Мистера Биста (крупный жирный шрифт, обводка, пословная подсветка),
  которые можно выключить;
- **размещает интригующий заголовок по центру между вебкой и геймплеем** (тёмная полоса 180 px);
  заголовок придумывает LLM, при откате берётся шаблон по типу реакции (`titles.py`);
  цвет текста выбирается: **белый / зелёный / жёлтый / красный / синий** (`/titlecolor`), фон остаётся чёрным;
- собирает раскладку: вебка сверху / экран снизу, вебка на весь экран, или просто кадр на весь экран;
- может следить за эфиром и каждые N минут присылать 1–2 лучших момента.

**Никаких платных API и ключей, кроме токена Telegram-бота.** Whisper и LLM работают на твоей
машине, офлайн и без лимитов.

## Установка

Нужны Python 3.10+ и `ffmpeg` (должен быть в `PATH`).

```powershell
cd clipper_bot
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

> `opencv-python-headless` зафиксирован на **4.x**: в 5.x убрали `CascadeClassifier`.
> Нужные Haar-каскады уже лежат в `clipper_bot/cascades/`. На Windows с кириллическим
> путём они автоматически копируются в ASCII-папку во Temporary — это особенность OpenCV.

### Локальный ИИ (Ollama)

1. Установи Ollama с https://ollama.com
2. Скачай модель (один раз, ~2 ГБ):

```powershell
ollama pull qwen2.5:3b
```

3. Убедись, что Ollama запущена (обычно стартует сама и слушает `http://127.0.0.1:11434`).

Проверить статус можно командой бота `/ai` или `/settings`.

Если Ollama не запущена — бот автоматически использует старую эвристику, так что работоспособность
сохраняется.

## Запуск

```powershell
python bot.py
```

Токен лежит в локальном файле `clipper_bot/.env` (он не в исходниках). Для запуска
достаточно двойного клика по `start.bat`.

Если `api.telegram.org` недоступен напрямую, укажи прокси в `.env`:

```
TELEGRAM_PROXY=http://127.0.0.1:10809
```

Поддерживаются HTTP/SOCKS-прокси (например, локальный Clash на порту 10809).
Тот же прокси используется для скачивания YouTube (`DOWNLOAD_PROXY`, по умолчанию берётся из
`TELEGRAM_PROXY`).

Если на диске C: мало места, модель Ollama можно держать на другом диске:

```
OLLAMA_MODELS=D:\OllamaModels
```

(уже выставлено в системе в этом проекте).

Можно проверить пайплайн без бота:

```powershell
python cli.py "https://youtube.com/watch?v=..."
```

### Настройки через переменные окружения

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | — | токен бота (можно в `.env`) |
| `TELEGRAM_PROXY` | — | прокси для Telegram, напр. `http://127.0.0.1:10809` |
| `WHISPER_MODEL` | `base` | модель Whisper: `tiny`/`base`/`small`/`medium` |
| `WHISPER_DEVICE` | `cpu` | `cpu` или `cuda` |
| `WHISPER_COMPUTE_TYPE` | `int8` | `int8` (CPU) или `float16` (GPU) |
| `LLM_ENABLED` | `true` | использовать локальную LLM для поиска моментов |
| `OLLAMA_MODEL` | `qwen2.5:3b` | модель Ollama (нужно сначала `ollama pull`) |
| `OLLAMA_URL` | `http://127.0.0.1:11434` | адрес локального сервера Ollama |
| `LLM_CHUNK_SECONDS` | `600` | размер фрагмента транскрипта за один запрос |
| `LLM_MAX_CHUNKS` | `24` | максимум фрагментов за видео (защита от очень длинных эфиров) |
| `LLM_TIMEOUT` | `180` | таймаут одного запроса к Ollama, сек |
| `LLM_FALLBACK` | `true` | откат на эвристику при недоступности LLM |
| `LLM_GLOBAL_RANK` | `true` | финальный проход модели: убрать повторы и уточнить границы |
| `WEBCAM_BOX` | — | ручной прямоугольник вебки `x,y,w,h` в долях кадра, напр. `0.02,0.05,0.26,0.29` |
| `VISUAL_ENABLED` | `true` | проверять мимику в отобранных клипах |
| `VISUAL_SAMPLES` | `10` | сколько кадров смотреть на каждый клип |
| `VISUAL_MIN_SCORE` | `0.3` | порог, при котором визуальная реакция повышает оценку момента |
| `MIN_CLIP` / `MAX_CLIP` | `15` / `60` | границы длительности клипа, сек |
| `MAX_CLIPS` | `5` | максимум клипов с одного видео |
| `SUBTITLES` | `true` | субтитры включены |
| `TITLE_COLOR` | `white` | цвет заголовка: `white`/`green`/`yellow`/`red`/`blue` |
| `LAYOUT` | `top_webcam_bottom_screen` | `none` / `webcam_full` / `top_webcam_bottom_screen` |
| `MONITOR_INTERVAL` | `10` | интервал авто-слежения, минут |
| `MONITOR_TAIL` | `180` | сколько последних секунд эфира скачивать за проверку |
| `CLIPPER_WORK_DIR` / `CLIPPER_OUTPUT_DIR` | `work` / `output` | папки для временных и готовых файлов |

## Команды бота

```
/start                  помощь
/clip <url>             сделать нарезки из YouTube-ссылки
/subtitles on|off       субтитры как у Мистера Биста
/titlecolor white|green|yellow|red|blue — цвет заголовка на чёрной полосе
/layout none|webcam_full|top_webcam_bottom_screen
/ai on|off              локальный LLM (Ollama) для поиска моментов по смыслу
/webcam x,y,w,h|auto    прямоугольник вебки в долях кадра (если авто не нашёл)
/auto <url> [минуты]    следить за эфиром, кидать лучший момент каждые N минут
/stopauto               остановить слежение
/settings               текущие настройки и статус Ollama
```

## Как устроено

```
downloader.py   yt-dlp: YouTube / Twitch / Drive и др.
transcriber.py  faster-whisper: слова с таймкодами
audio_cues.py   локальный анализ звука: громкость, тон, резкость -> метки реакций
llm.py          клиент локальной модели Ollama (stdlib urllib, без зависимостей)
semantic.py     чанки транскрипта + метки звука, запрос к LLM, финальный отбор
visual_cues.py  мимика только в отобранных клипах: улыбка/рот/движение (Haar)
titles.py       интригующие заголовки (LLM или шаблоны по типу реакции)
analyzer.py     запасной путь: громкость + словари эмоций -> окна 15–60 c
subtitles.py    ASS-субтитры с пословным караоке
layout.py       поиск вебки через OpenCV + ffmpeg-фильтры 9:16
clipper.py      сборка пайплайна и рендер через ffmpeg
bot.py          Telegram-интерфейс и планировщик мониторинга
```

LLM получает расшифровку вида `[12.3] привет вау как это возможно` и возвращает строго JSON со
списком моментов: `start`, `end`, `category`, `score`, `reason`. Код проверяет, что таймкоды
реальные, длина 15–60 c, убирает пересечения и оставляет лучшие.

## Ограничения (честно)

- **Качество зависит от модели.** `qwen2.5:3b` — компромисс между скоростью и качеством на CPU.
  На слабом ПК один фрагмент может обрабатываться десятки секунд. Можно поставить другую модель
  через `OLLAMA_MODEL` (например `llama3.2:3b`) или включить GPU.
- **Мимика распознаётся грубо.** Haar-каскады ловят улыбку/открытый рот/наклон, но не тонкие
  эмоции. Это лёгкий бонус к основному анализу, а не замена модели распознавания лиц.
  Если лицо не видно (вебка закрыта, аватарка) — визуальная часть просто не влияет на выбор.
- **Вебка ищется по лицу через три Haar-каскада.** Если вебка анимированная, в маске или не в углу —
  авто-детекция может не сработать. Тогда используй `/webcam x,y,w,h` или `WEBCAM_BOX`, чтобы задать
  прямоугольник вручную (доли кадра, например `0.02,0.05,0.26,0.29`), либо `/webcam auto`.
- **`/auto` для live-эфиров — best effort.** Команда пытается скачать только последние
  `MONITOR_TAIL` секунд через `yt-dlp --download-sections`; если YouTube отдаёт не весь хвост,
  бот откатывается к скачиванию целиком. На очень длинном эфире это может быть медленно.
- Это **код**, а не готовый сервис: для работы 24/7 его нужно запустить на постоянно включённом
  ПК или VPS (там же понадобятся `ffmpeg`, Ollama и 2–4 ГБ оперативной памяти).
